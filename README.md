# Invisiron Website

React/Vite implementation of the Invisiron website prototype.

## Project Structure

- `src/` - React application source.
- `public/` - static assets served by Vite.
- `worker/` - Sites worker entrypoint.
- `scripts/` - build and packaging helpers.
- `tests/` - Node test coverage for the Sites worker/package output.
- `docs/` - design QA notes and source-reference captures.
- `.openai/` - hosting configuration for Sites.

## Commands

```sh
npm run dev
npm run build
npm run test:sites
```
